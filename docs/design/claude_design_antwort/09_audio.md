# Audio-Ideen

8-Bit/Chip-Sounds mit kurzen Rauschanteilen, 22 kHz, mono, 0,1–0,6 s; Musik je Biom als Loop. Alle Sounds leicht zufällig in Tonhöhe (±4 %) variieren, damit Wiederholung nicht nervt.

| Was | Sound |
| --- | --- |
| Spieler Schritt | zwei kurze Rausch-Klicks (Hochpass 2 kHz, 40 ms), auf Stein heller, auf Moos dumpfer, im Wasser Platschen (Tiefpass 600 Hz + kurzes Rauschen) |
| Dash | Sweep 300→900 Hz in 120 ms (Sägezahn, leise) + Rauschhauch |
| Schwert-Schwung / Treffer | Rausch-Sweep 1,5→4 kHz 90 ms; Treffer: Sinus-Thump 120 Hz 60 ms + Klick |
| Bogen | Sehne: Sinus 440→220 Hz 80 ms; Pfeil-Einschlag: Holz-Klick 2 kHz 30 ms |
| Magierstab | Orb-Flug: leiser Sinus 880 Hz mit Vibrato; Explosion: Rauschburst 300 ms Tiefpass 400→100 Hz + Sub-Thump 60 Hz |
| Herz verlieren | fallendes Dreieck 600→200 Hz 200 ms + dumpfer Schlag; Schild-Treffer: metallischer Ping 1,2 kHz mit schnellem Decay |
| Gold | kurzer Rechteck-Doppelton 1 kHz → 1,5 kHz (je 40 ms); Kristall: glasiger Sinus-Dreiklang aufwärts 300 ms |
| Schleim hüpfen / landen | Sinus-Blip 180→90 Hz 120 ms; Landung: nasses Klatschen (Rauschen Tiefpass 800 Hz, 60 ms); Teilung: zwei Blips versetzt |
| Skelett | Knochenklappern: 3–4 Holzklicks 1–3 kHz zufällig in 150 ms; Tod: Klappern + Fall; Wiederaufstehen (Totengräber): umgekehrtes Klappern |
| Bogenschütze | Spannen: Knarzen (Rauschen 200 ms, Bandpass 500 Hz); Schuss wie Spieler-Bogen tiefer |
| Schattenwesen | Flüster-Rauschen Bandpass 1 kHz mit langsamem Tremolo; Krallenhieb: Rausch-Sweep hoch; Blenden: hoher Sinus 3 kHz 400 ms ausklingend |
| Bomber | Lunte: Zisch-Rauschen 6 kHz lückenhaft; Explosion wie Stab, lauter |
| Golem / Glutgolem | Schritt: Sub-Thump 50 Hz + Steinknirschen; Faust: Thump + Rauschburst, Glutgolem zusätzlich Zischen |
| Nekromant | Zauber: Sinus-Akkord moll 200 ms mit Filter-Sweep; Beschwören: tiefes Dröhnen 80 Hz 600 ms + Knochenklappern |
| Bosse | Knochenkönig: Metall-Ping für Schild, Kettenrasseln; Schleimkönigin: tiefes Blubbern, Sprung-Landung mit Sub; Schattenlord: Teleport = Rauschen rückwärts + Ping; Glutgolem: Stampfer = Sub 40 Hz + Funkenzischen |
| Gegner-Quellen | Grab: Erde-Knirschen (Rauschen 300 Hz, 400 ms) + Klappern; Pfütze: Blubbern (3 Blips 150→250 Hz); Bodenriss: aufsteigender Sinus 100→400 Hz mit Flüstern; Lavaspalte: Zischen + Sub-Dröhnen; Tor: Metallrasseln + Kettenzug |
| Türen | Holz: Knarren (Sägezahn 90 Hz mit Vibrato 300 ms) + Klack; Fallgitter: Metallrasseln + Schlag; Runen: Glas-Shimmer; Ranken: nasses Rascheln |
| Fallen | Stacheln: Metall-Zischen 80 ms; Flammendüse: Zisch-Rauschen 500 ms mit Tiefpass-Sweep; Pendel: Woosh (Rauschen Bandpass 400 Hz an- und abschwellend) |
| Einsturz | Risse: Knacken (3 Klicks); Fall: Steinrutschen (Rauschen 400 ms Tiefpass fallend) + Sub |
| Intro-Muster | Tür zu: Schlag + Hall; Kameraschwenk: leiser Drone; Banner: Kurzer Akkord (Dur für Ruhe, Moll für Kampf); Countdown: drei Ticks (Rechteck 800 Hz 40 ms), „Los“: Tick 1,2 kHz länger |
| Welle / Fortschritt | Welle geschafft: Gong (Sinus 220 Hz + Obertöne, 1 s Decay); Seele gesammelt: Glas-Ping aufsteigend; Flamme getroffen: Zischen + tiefer Puls; Flamme stirbt: lang abfallender Sinus |
| UI | Hover: Klick 2 kHz 20 ms; Bestätigen: Doppelklick aufwärts; Abbrechen: Klick abwärts; Kauf: Gold-Doppelton + Klack; Upgrade: Dur-Dreiklang 300 ms |
| Ambiente je Biom | Krypta: Tropfen (zufällige Sinus-Pings 2 kHz) + tiefes Luftrauschen; Grotte: Blubbern + Tropfen dichter; Schattenreich: Flüstern-Rauschen + seltener Glas-Shimmer; Glutkammer: Glut-Knistern (Rausch-Klicks) + Sub-Dröhnen; Dorf: Vögel (kurze Sinus-Triller), Wind, Hühner |
| Musik | Dorf: Dur, 90 bpm, Flöte+Harfe (Rechteck + Dreieck); Krypta: Moll, 100 bpm, Orgelflächen; Grotte: pentatonisch, 110 bpm, Marimba-Rechteck; Schattenreich: chromatische Flächen 80 bpm; Glutkammer: treibend 130 bpm mit Rausch-Drums; Boss: Tempo +20 %, Phase 2 Oktave höher; Lagerfeuer: Dorfmotiv langsam, nur Harfe |
